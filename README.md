# ADT — Платформа для ведения личного графика занятости & Финансового учета

**ADT (Activity & Day Tracker)** — защищенная персональная веб-платформа для планирования и управления личным расписанием на день, неделю, месяц и год, с категоризацией дел (Учеба, Работа, Иное) и встроенным финансовым учетом (доходы и расходы по каждому делу).

---

## 🔐 Авторизация и доступ

Вход на платформу строго защищен серверным паролем с валидацией через зашифрованные JWT в `HttpOnly` Cookie.

| Режим доступа | Пароль по умолчанию | Права и возможности |
| :--- | :--- | :--- |
| **Основной (Личный)** | `11111111` (8 единиц) | **Полный доступ**: создание, редактирование, удаление дел, управление финансами, аналитика, экспорт/импорт. |
| **Гость (Гостевой доступ)** | `88888888` (8 восьмерок) | **Только просмотр**: безопасный режим для демонстрации расписания без права изменения данных. |

---

## 🚀 Основные возможности

1. **Режимы отображения расписания**:
   - **День**: почасовая шкала (00:00 - 23:00), блоки дел, индикаторы доходов/расходов.
   - **Неделя**: 7-дневная сетка с ежедневными финансовыми балансами.
   - **Месяц**: классический календарь с бейджами задач и сводкой на каждый день.
   - **Год**: интерактивная тепловая матрица занятости (heatmap) и динамика баланса по месяцам.

2. **Типы занятости**:
   - 🎓 **Учеба** (Cyan)
   - 💼 **Работа** (Emerald)
   - ✨ **Иное** (Purple)

3. **Финансовый блок каждого дела**:
   - Поле **Доход (+₽)** и поле **Расход (-₽)**.
   - Заметка к финансам (аванс, оплата курсов, покупка оборудования и т.д.).
   - Автоматический подсчет общего баланса за день, неделю, месяц, год.

4. **Аналитика**:
   - Интерактивные графики (BarChart и PieChart) распределения бюджета и доходов/расходов по категориям занятости.

5. **Безопасность (Vercel Ready)**:
   - Серверная проверка паролей (пароли никогда не передаются в клиентский бандл).
   - Защита от перебора паролей (Rate Limiting).
   - Security Headers: `Content-Security-Policy`, `X-Frame-Options: DENY`, `Strict-Transport-Security`, `no-sniff`.
   - Middleware для защиты всех страниц и API.

6. **Резервное копирование**:
   - Экспорт в **JSON** (полная копия) и **CSV** (таблица для Excel).
   - Импорт резервной копии в 1 клик.

## ☁️ Размещение (Деплой) на Vercel

### Способ 1: Через GitHub и Vercel Dashboard (Рекомендуемый)

1. Создайте репозиторий на [GitHub](https://github.com/) и загрузите проект:
   ```bash
   git init
   git add .
   git commit -m "Initial ADT release"
   git remote add origin https://github.com/<ваш_аккаунт>/adt-platform.git
   git branch -M main
   git push -u origin main
   ```

2. Откройте [Vercel Dashboard](https://vercel.com/new) и импортируйте ваш репозиторий.

3. В разделе **Environment Variables** (Переменные окружения) добавьте:
   - `MAIN_PASSWORD` = `11111111` (или ваш собственный сложный пароль)
   - `GUEST_PASSWORD` = `88888888` (или ваш гостевой пароль)
   - `SESSION_SECRET` = `adt_super_secret_session_encryption_key_2026_vercel_production_998877`

4. Нажмите **Deploy**. Через 1 минуту платформа будет доступна по вашему личному домену `*.vercel.app`!

## 💻 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка и проверка
npm run build
```

Приложение откроется по адресу `http://localhost:3000`.
